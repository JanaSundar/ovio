About Ovio

Components that feel like your site, not ours.

Ovio is an open-source kit for developer websites — portfolios, project pages, docs and profiles. Every component ships with four renderers that change material, type, shape, interaction and motion, not just colour.

01 Pick a component Contribution graphs, repo cards, star history, tickets — built for the things developers actually show.
02 Choose a world Minimal to keep it clean, Craft to make it feel made, Retro for nostalgia, Toy to play with it. Each is its own renderer over shared logic and accessibility.
