# Ovio — mockups not built yet

These are the reference mockups for the two components that are not part of the library yet. Every
other component, and the site, has been rebuilt in `components/ovio/` and `app/`, and its mockup
removed.

- `source/Contribution Drum.dc.html`
- `source/Contribution Trays.dc.html`

They run on `source/support.js` (template runtime) and `source/numberflow.js` (rolling numbers).
Serve `source/` over HTTP (for example `npx serve source`) to open them. They are a spec, not code
to ship: build with Motion for React and `@number-flow/react`.
